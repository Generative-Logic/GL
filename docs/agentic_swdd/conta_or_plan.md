## Follow-up: quotient-case admission diagnosis

The maintainer requested the precise gate after the multiplication rule's missing-premise demand. Diagnosis uses the existing full-chain sacred trace; no source/configuration change or new pipeline run is needed. The earlier implementation and verification remain complete.

**Observed evidence.**  scans every ENTRY/EXIT frame of . Both strict-order demand keys first appear at EXIT #11. Both quotient `or12` statements first appear at EXIT #20, at `main`, and remain live through EXIT #26. Across all frames neither statement appears in `localEncodedStatements`, either OR parking index, or the cohort-count registry. The final origin entry names the natural-number trichotomy rule; origin is supporting history, not the control-flow evidence.

**Gate, inferred from the trace's non-local classification and current source.** `prover.hpp::standardProcessing` sends ordinary ancestor statements to `prover.cpp::addExprToMemoryBlock` with status 3. Its `willDisintegrate` predicate permits status 3 only for compact implications and negated compact existences. A positive `or12` is neither, so it registers as a non-local statement without calling `disintegrateExpr2` or `consumeOrLeavesCohort`. The flag-5 exception does not apply: `disintegrateExprCore2` records existence-spawning compacts in `witnessMeta`, and `disintegrateExpr2` relays those compacts, not the quotient OR. Local statuses 0/1 and direct fact-load status 4 would register locally, which the trace excludes. This diagnosis reconstructs the status from source and stored locality; the sacred dump does not log the transient status argument directly.

**Why existing demand does not recover it.** `memory.cpp::drainAdmissionKeysOrdis2` inserts the key and calls `prover.cpp::revisitRejectedOrdis2`. That function probes only the matching parked run and returns on absence. The ordinary-mail path never filed that run. A later repeated deposit is rejected by `addExprToMemoryBlock`'s Site F because the OR is already known. Thus demand exists before supply, but supply bypasses the admission consumer. Depth and empty-goal eligibility are downstream of the blocking gate.

**Classification.** Existing mail/disintegration architecture restriction, not a missing demand key or demonstrated key-generation defect. The contradiction lifecycle change did not change this earlier gate. Any remedy must explicitly decide how a demanded inherited OR becomes eligible for local case processing; no remedy is implemented here.
